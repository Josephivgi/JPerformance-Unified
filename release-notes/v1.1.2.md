**Improved**

- Stop buttons in app lists fit on screen. You no longer scroll sideways to reach them.
- Every Stop asks first. The dialog names the app, says how many processes it ends and how much memory they use, and reads those numbers fresh when it opens. If the app already closed, it says so instead.
- Force stop says how many processes it ends before you confirm.
- Clean up > What each app is running: Stop all lists what is inside the group before you confirm. Stop selected lists each item it will stop.
- Delete dialogs in Storage list up to 40 files in a scrolling box, so you can check what will be deleted.
- Lists hold still while you point at them, use the keyboard in them, or select text. They catch up once you stop. After you press Stop, Retry now or Start recording, the result shows right away.
- Search boxes keep your cursor where it was when the list updates.
- Apps that run on a shared program (node, python, electron) are named by that program in totals over time, and the same name is used on every page.
- In a narrower window (about 1000 pixels), the app details show above the list and the summary tiles use two columns.

**Fixed**

- Clean up: the reason column could shrink to one letter wide, so the text ran down the page one letter per line.
- Clean up: items Windows would not let you stop stay ticked, instead of looking handled.
- Storage: the space bar counted the Recycle Bin twice.
- Charts said "peak" for numbers that are the highest average over a stretch of time. They now say "highest average".
- Sizes just under the next unit showed as "1024 KB". They now show as "1.0 MB".
- A server that timed out offers Retry now, the same as one that failed to log in.
