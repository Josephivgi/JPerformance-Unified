**New**

- This PC > Storage > Apps lists every installed app by how much space it takes, its program folder and its data in AppData, biggest first. Each one has an Uninstall button. Apps with a quiet uninstaller are removed without more steps; others open their own uninstaller. Files an app leaves behind are listed afterwards, with a button to move them to the Recycle Bin. Microsoft Store apps are listed too.
- This PC > Storage frees up disk space without scanning first. Caches are listed by group (Windows, Browsers, Apps, Developer tools, Games) with their size: temporary files, thumbnails, crash dumps, shader caches, each browser, every Electron app on the PC (VS Code, Discord, Slack and others), Roblox, and npm, pnpm, pip, Yarn, Bun, Rust, Go, .NET, Electron, Gradle and Playwright downloads. Select recommended picks the ones that are cheap to get back. A cache whose program is open says so, and each one can show the folders behind it.
- Clearing caches shows its progress and can be cancelled. Afterwards it says how much was freed and what was left because a program is using it. Temporary files are only deleted when nothing in them changed for a day, and a folder a running program has files open in is left alone.
- Storage > Downloads folder lists what sits in Downloads, biggest first. Filter it to things not changed for 30 days up to a year, or press Select installers and archives.
- Storage > Windows files shows the big files Windows keeps for itself (hibernation file, page file, an earlier Windows version) and how to remove each.
- Storage > Scan looks through your user folder or a whole drive and shows what fills it: folders by size, the largest files, duplicate files, and project build folders (node_modules, Rust target, Python environments, .NET bin and obj, web build caches, Unity Library). One button selects the build folders of projects you have not touched for 30 days or longer. Check what you want gone and press Move to Recycle Bin, or delete for good. Windows, program folders and your main folders can never be deleted.

- This PC > Clean up shows every app with everything it started. For example, T3 Code and its agent sessions and helpers show as one row with their total memory. Open an app to stop one agent session or helper on its own, without touching other programs that share its name.
- Clean up suggests what is safe to stop: helpers such as node, python or a shell that kept running after the app that started them closed, and agent sessions that have been idle for 30 minutes. Check the ones you want and press Stop selected.
- Automatic clean-up, in Clean up, can end idle shells left over from closed apps on its own after they have been idle for 10 to 60 minutes. It is off until you turn it on, and it never touches anything with a window, anything that looks like a server, Windows itself, or other users' processes. Everything it stops is listed under Recently stopped.
- A "This PC is slow right now" bar appears on every page when the processor stays busy, memory is nearly full, or committed memory is near its limit. It names the apps behind it and has a Stop button for each.
- Committed memory (RAM plus page file) is recorded and shown on This PC > Now, in History, and on Clean up. A new finding warns when it stays above 90%, which is when apps freeze or crash even though memory looks free.
- Running has a search box and a Committed column that shows the private memory each app holds.
- Findings now say what to do about them, and offer a Stop button when the app behind them is still running.
- Server findings include read-only commands you can copy and run on the server to look closer, such as which folders fill a disk.
- Server findings name the longest stretch of high CPU or memory, when it started, and which services, containers or VMs were behind it.
- Server history has separate charts for network in and out, disk read and write, CPU waiting on disk, swap, and CPU taken by the host.

**Improved**

- When a new version is ready, the sidebar shows an Update now button. It shows what changed first, then installs and restarts.
- Stop asks before it ends more than one process, or a program without a window that cannot be asked to save first.
- Lists hold still while the pointer is over them, so a Stop button does not move onto a different app.
- Apps show their friendly name, with the file name underneath.
- Servers reconnect on their own after a network drop or a reboot, waiting a little longer each time (30 s up to 10 minutes). A rejected key or changed host key still waits for you to press Retry, so fail2ban cannot ban you.
- ZFS cache that Linux can take back is counted as free, so Proxmox and other ZFS servers no longer show as out of memory.
- When a host key file is set in your SSH config, only that key is offered, so other keys in ssh-agent cannot lock the login out.

**Fixed**

- Samples were sometimes lost with "database is locked" when several servers were recorded at once.
- A server's error message could show a harmless message from the server instead of the real reason the connection failed.
- JPerformance Unified could stop its own window or recorder from the Running list.
