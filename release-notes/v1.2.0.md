**New**

- RAM Auto Cleanup, a page of its own, shows what the background RAM cleaner did. Every pass is listed with the memory in use when it started and after it finished, which apps were emptied and how much memory moved out of RAM, and the biggest first. A summary at the top says how much has been freed in total, when the last pass ran, and whether memory is over the level now. A Free RAM now button runs a pass straight away; nothing is closed by it.
- Where the memory came from lists every app the cleaner has emptied, how many times, and how much in total, so an app that keeps filling up shows at the top.
- Memory leaks it found: apps whose memory kept climbing for hours while doing little and never came back down. Each one shows how far it climbed over the last day, how fast it was gaining memory, the CPU it used while it grew, how much of it the cleaner has already freed, and a small chart of the climb. A leak is only called one when it was climbing for two hours or more, gained at least 200 MB, stayed near its highest, and used little of the processor, so a busy app that fills up and lets go is not listed. Apps that stopped climbing stay listed as such.
- Leaks are looked for every five minutes in the background, from the history the recorder already keeps. The sidebar shows how many are still growing.

**Improved**

- Clean up has a button through to RAM Auto Cleanup, so the switch that turns the cleaner on and the record of what it did are one click apart.
- The memory a pass frees is now recorded per pass, not only per app, and kept for as long as the rest of the history.

**Command line**

- `--free-ram [minutes]` runs one pass now and lists what it freed, and `--leaks` prints the leaks found and the recent passes.
